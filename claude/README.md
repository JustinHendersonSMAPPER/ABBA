# Claude Development Files

This directory contains Claude-specific files used during development. These files should be cleaned up before final commits.

## Directory Structure

- **`scripts/`** - Debug and test scripts created during development
- **`documentation/`** - Claude-generated analysis and documentation  
- **`temp_files/`** - Temporary files for testing and debugging
- **`notes/`** - Development notes and findings

## Guidelines

1. **Always place Claude-generated debug scripts here** instead of in the project root
2. **Clean up before commits** - remove or organize files that are no longer needed
3. **Use descriptive names** for files to make cleanup easier
4. **Document important findings** in the notes/ folder for future reference
